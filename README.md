# EventVenue

A decentralized event management platform enabling organizers to publish and manage events on the Stacks blockchain.

## Features
- Event publication with comprehensive venue information
- Support for multiple event types (Conference, Concert, Workshop, etc.)
- Venue classification system
- Capacity management
- Organizer-controlled event lifecycle

## Smart Contract Functions
- `publish-event`: Create and publish a new event
- `unpublish-event`: Cancel an event publication
- `get-event`: Retrieve event details
- `get-organizer`: Get event organizer address

## Testing
